Privacy Policy

Last updated: September 1, 2026

Summary: The extension is designed to keep job-application profile data, selected documents, preferences, and learned answers in browser extension storage. It does not require a user account or a developer-operated profile database.

1. Purpose

Automatic Easy Apply Jobs (“the Extension”) helps users complete online job application forms by autofilling reusable information, attaching user-selected documents, remembering optional reusable answers, and highlighting fields that still require manual review.

2. Information the Extension Handles

The Extension may process and store information voluntarily provided by the user for job applications, including:

  • Name and surname
  • Email address and phone number
  • Address, city, postal code, province/region, country, and other location information
  • Nationality
  • LinkedIn, GitHub, portfolio, and website URLs
  • Current job title, company, work experience, and other professional profile information
  • Salary expectations, hourly rate, availability, or start date
  • Resume/CV, cover letter, and portfolio documents selected by the user
  • Job application answers saved through the “Remember new answers” feature
  • Optional diversity or equal-opportunity information entered by the user, such as gender, race/ethnicity, disability status, veteran status, pronouns, or similar application information

The Extension may also read job application page content such as form labels, questions, input fields, dropdown options, checkbox/radio options, and validation states solely to determine how to complete or review the application form.

3. Local Storage

Application profile information, learned answers, preferences, and user-selected documents are stored locally using browser extension storage. The Extension does not operate a remote database for storing users’ job application profiles, and the developer does not receive a copy of information kept solely in the user’s local extension storage.

4. Resume and Document Processing

When a user imports a CV or resume, the Extension may process the document locally to extract contact and professional information that can be added to the user’s application profile. User-selected CVs, cover letters, and portfolio files may be stored locally so they can be reused on compatible job application upload fields at the user’s request.

5. Sensitive Information Excluded from Saving and Learning

The Extension is designed not to save, learn, or automatically reuse sensitive credential, financial-account, or government-identification information, including:

  • Passwords, passcodes, PINs, OTPs, verification codes, 2FA/MFA codes, and security codes
  • Passport numbers, national/government identification numbers, Social Security numbers, tax identification numbers, driver’s-license numbers, and residence-permit numbers
  • Bank account, IBAN, routing, SWIFT, payment-card, CVV, and CVC information
  • API keys, access tokens, secret keys, and recovery codes

Fields identified as containing these types of information are intended to remain manual.

6. Learned Answers

If the user enables “Remember new answers”, the Extension may locally remember answers manually entered into job application forms so that similar questions can be completed in future applications. Users can view and delete individual learned answers or clear all learned answers from Settings. Sensitive fields described above are excluded from this feature.

7. Website Access

The Extension requires access to job application websites so it can detect application forms, read field labels and available options, fill locally stored profile information, attach user-selected documents, highlight unanswered fields, and display the on-page assistant. It does not use this access for advertising or behavioral profiling.

8. Sharing and Transfers

The Extension does not sell user data and does not provide user data to advertisers, data brokers, or unrelated third parties. When the user chooses to autofill a job application, locally stored information may be inserted into the employer’s or applicant-tracking-system’s form. The job website may receive that information when the user interacts with or submits the application. Users should review the privacy policy of the job website they are using.

9. Website/Domain Context

Some learned answers may be associated locally with a website or domain when needed to avoid reusing an answer in an inappropriate application context. The Extension does not use this information to build an advertising profile or general browsing-history database.

10. User Activity

The Extension does not perform keylogging and does not collect mouse-movement history, scrolling history, click analytics, or behavioral-advertising data. Local interactions with Extension controls may be processed only when needed for features such as dragging the on-page assistant or selecting a field to review.

11. Remote Code

The Extension does not download or execute remote JavaScript or WebAssembly. Executable extension code is packaged with the Extension.

12. Data Retention and Deletion

Information stored by the Extension remains in the browser until the user edits or deletes it, clears learned answers or documents, clears browser extension storage, or uninstalls the Extension. Profile information and learned answers can be managed from the Extension’s Settings page.

13. Data Security

The Extension is designed to minimize data collection and keep job-application information on the user’s device whenever possible. Users should avoid entering unnecessary sensitive information into their reusable application profile.

14. Children’s Privacy

The Extension is intended for job-application use and is not designed for children.

15. Changes to This Policy

This Privacy Policy may be updated if the Extension’s functionality or data practices change. The current version will be published at this URL with an updated “Last updated” date.

16. Contact

For privacy questions about Automatic Easy Apply Jobs, contact the developer through the support contact information on the Chrome Web Store listing.
