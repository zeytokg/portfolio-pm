What it does

One assistant for repetitive job application work.

01

Import a profile from your CV

Select a PDF, DOCX, DOC, or TXT CV and let the extension extract reusable contact and professional profile fields locally.

02

Fill common application fields

Recognizes common text fields, professional summaries, dropdowns, radio buttons, checkbox groups, salary fields, location fields, and more.

03

Attach your documents

Store a CV, cover letter, or portfolio file locally and reuse it on compatible upload fields; portfolio files can also match additional/supporting document requests.

04

Remember reusable answers

Optionally remember answers you enter inside job-application forms — including dropdown, radio, and checkbox choices — and reuse them on matching questions. Search and navigation controls are ignored.

05

Show what is still missing

Unanswered visible fields are highlighted so you can jump directly to the parts that still need manual review.

06

Keep sensitive fields manual

Passwords, OTPs, passport/ID numbers, banking and card details, API keys, and similar secrets are excluded from saved answers and autofill.

Privacy

Your application profile stays local to the extension.

The extension is designed to store profile data, selected documents, and learned answers in browser extension storage. It does not require an account or a developer-operated profile database. Sensitive credential and identity-number fields are intentionally excluded from learned answers.
