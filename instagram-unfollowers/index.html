How to use it

1
Log into instagram.com.

Keep the Instagram tab open while you run the tool.

2
Open your browser's developer console.

Windows/Linux: Ctrl + Shift + J    macOS: Cmd + Option + J

3
Copy the code below, paste it into the console, and press Enter.

If Chrome blocks pasting, it may show a self-XSS safety warning. Review the source first and follow Chrome's on-screen guidance before pasting.

4
Click "Scan now" in the panel that appears in the top-right corner.

Wait for the scan to finish, then review and filter the results before taking any action.
