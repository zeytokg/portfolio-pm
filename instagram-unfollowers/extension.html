Install the extension

by zeytokg

A small Chrome extension. Click the pink heart while you're on Instagram and the panel opens right there — no console, no bookmark juggling, no second click.

Heads up: Chrome only lets extensions install with one click through the official Chrome Web Store. Anything downloaded from a website — including this one — has to be added manually through Developer Mode. That's not a shortcut I skipped; it's a Chrome restriction that applies to every extension not published in the Store.

Install it (once)

♥Download the extension (.zip)

Unzips into a single folder — that's the folder you'll point Chrome at below.

1

Unzip the downloaded file.

2

Open chrome://extensions in Chrome.

3

Turn on Developer mode (top-right toggle).

4

Click Load unpacked and select the unzipped folder.

5

Open or refresh instagram.com.

Use it

1

A pink heart appears on the page — drag it anywhere you like.

2

Click it (or the toolbar icon) — the panel opens right away.

3

Click "Scan now". No console, no second click, nothing to paste.

Why not the Chrome Web Store

  • Automated bulk-unfollow tools are a category Google routinely rejects or later removes from the Store, because they act on a third-party service (Instagram) in ways that service's own terms don't allow.
  • Submitting would mean a review process, a developer fee, and a real chance of rejection or takedown later — for a personal tool, that's not worth it.
  • Loading it unpacked costs you thirty seconds and gives the exact same result, with the source fully visible before you install it.
