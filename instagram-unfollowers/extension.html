Install the extension

by zeytokg

A small Chrome extension. Click the pink heart while you're on Instagram and the panel opens right there — no console, no bookmark juggling, no second click.

Now on the Chrome Web Store: install the extension directly from its official store listing. Installation is handled directly by Chrome.

Install it (once)

♥Open in Chrome Web Store

Install from the official store listing, then refresh Instagram.

1

Open the Chrome Web Store listing above.

2

Click Add to Chrome and confirm the installation.

3

Open instagram.com and log in to your account. The extension needs an active Instagram session in this browser; if you were already signed in, refresh the tab.

Login & privacy: the extension never asks you to enter or send your Instagram password to the developer and does not store your login credentials. It uses the Instagram session already open in your browser. The developer does not maintain a separate developer-controlled database of the Instagram account information processed by the extension.

Use it

1

A pink heart appears on the page — drag it anywhere you like.

2

Click it (or the toolbar icon) — the panel opens right away.

3

Click "Scan now". No console, no second click, nothing to paste.

Why install from the Chrome Web Store

  • Install directly from the official store listing in a couple of clicks.
  • Chrome handles installation and extension updates for you.
  • You can still review the published console script and security information on this site.
