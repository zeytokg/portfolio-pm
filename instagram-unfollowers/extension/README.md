# Instagram Unfollowers Chrome Extension

The extension is available on the Chrome Web Store:

https://chromewebstore.google.com/detail/instagram-unfollowers-by/nncocnefbohhghckdiaffdiglocllahj?authuser=0&hl=tr

## Install

1. Open the Chrome Web Store listing above.
2. Click **Add to Chrome** and confirm the installation.
3. Open or refresh `instagram.com`.
4. Click the pink heart (or the toolbar icon) to open the panel.

The source files in this folder are kept for transparency and development.
